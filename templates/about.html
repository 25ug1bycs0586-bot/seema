ABOUT THIS PROJECT

Career guidance that keeps its limits clear.

ResumeAI is a student-focused resume analyzer and career exploration tool for learning and placement-cell demonstrations.

HOW IT WORKS

Practical guidance, with receipts.

ResumeAI extracts text from PDF and DOCX files, detects skills from a local keyword catalogue, compares them with editable role requirements, and creates a learning roadmap. Optional OpenAI-assisted summary and suggestions are clearly labeled when enabled.

Without an API key, the complete core flow uses a rule-based analyzer. It never labels fallback output as AI-generated. Model output is constrained to summary and writing suggestions and is checked before it is shown.

What the scores mean

Resume quality uses configurable heuristic categories. Job match is the proportion of required catalogue skills detected in your resume text. Neither is a hiring probability, assessment of potential, or exact ATS simulation.

Fairness & limitations

The app does not rank candidates by sensitive personal characteristics and is not an automated hiring decision system. Keyword detection can miss context, and a skill not found in your resume may still be a skill you possess.

PRIVACY NOTICE

Your resume data

  • Uploaded files are parsed in memory and are not stored as files.
  • Extracted resume text and the report are saved to your account so you can use history and revisit results.
  • Delete a report from Analysis history to delete its saved report and learning progress.
  • If you configure the optional AI service, resume text is sent to the configured OpenAI API for summary and writing suggestions. Do not use the AI option unless that processing is acceptable to you.
  • Do not upload information you do not want processed. Avoid unnecessary personal details.
Scanned PDF?

OCR is not included. If little text can be extracted, use a text-based PDF or paste the resume text directly.

Technology

Flask · SQLite / SQLAlchemy · PyMuPDF · python-docx · Bootstrap · Chart.js · optional OpenAI API
